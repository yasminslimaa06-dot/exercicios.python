# Agenda de contatos

programa em Python, feito no terminal, para gerenciar uma agenda de contatos. Os dados ficam salvos em arquivos,então não se perdem ao fechar o programa.

## Funcionalidades

- Adicionar contato(sem nome ou telefone vazio,sem duplicados)
- Buscar contato pelo nome
- Listar contatos em ordem alfabética
- Remover contato
- Editar telefone
- Salvar e carregar os dados automaticamente('agenda.txt')

## Como rodar

1. Instale o Python 3.
2. Abra a pasta do projeto no terminal.
3. Execute:

python agenda.py

## Conceitos usados 

- Funções
- Dicionários
- Laço 'while' e menu com 'if/elif/else"
- Leitura e escrita de arquivos
- Tratamento de erros com 'try/except'
- Validação de entradas com '.strip()'
