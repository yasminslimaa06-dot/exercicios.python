# 📦 Controle de Estoque

Programa em Python, feito no terminal, para controlar o estoque de uma loja. Os dados ficam salvos em arquivo e não se perdem ao fechar o programa.

## Funcionalidades

- Cadastrar produto (nome, quantidade e preço)
- Listar produtos com valor de cada item e valor total do estoque
- Mostrar o produto com menos unidades
- Dar entrada e dar saída (o estoque nunca fica negativo)
- Remover produto
- Salvar e carregar os dados automaticamente (`estoque.txt`)

## Como rodar

1. Instale o Python 3.
2. Abra a pasta do projeto no terminal.
3. Execute:

   python estoque.py

## Conceitos usados

- Funções
- Dicionários aninhados
- Menu com `while` e `if/elif/else`
- Leitura e escrita de arquivos
- Tratamento de erros com `try/except`
- Validação de entradas
